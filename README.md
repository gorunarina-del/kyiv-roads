# Київ: дороги — PWA

Карта Києва на одному екрані: затори TomTom, ремонти й перекриття КМДА, збережені маршрути з часом у дорозі.
Застосунок не використовує GPS телефона, тому підміна координат під час тривоги на нього не впливає.

## Файли
| Файл | Що це |
|---|---|
| `index.html` | увесь застосунок |
| `sw.js` | робота офлайн: оболонка + кеш переглянутих плиток карти |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | іконка на головному екрані |
| `cloudflare-worker.js` | запасний посередник, лише якщо ремонти не вантажаться |

## 1. Публікація на GitHub Pages (≈5 хв)
1. github.com → **New repository** → назва, напр. `kyiv-roads`. Тип **Private** підходить лише на платному плані; на безкоштовному Pages працює з **Public**. Ключі в коді не зберігаються, вони лишаються на вашому телефоні.
2. **Add file → Upload files** → перетягнути всі файли з архіву (крім README за бажанням) → **Commit**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 хв застосунок буде за адресою `https://<ваш-логін>.github.io/kyiv-roads/`.

## 2. На телефоні
- **Android (Chrome):** відкрити адресу → ⋮ → «Додати на головний екран».
- **iPhone (Safari):** відкрити адресу → «Поділитися» → «На екран „Додому“».

## 3. Ключі (вводяться в застосунку: вкладка «Налаштування»)
- **TomTom** (затори, маршрути, ділянки): developer.tomtom.com → реєстрація → Dashboard → Keys → скопіювати ключ.
  Безкоштовного ліміту вистачає на особисте користування: застосунок оновлює дані раз на 2 хв і лише поки відкритий.
  У Dashboard варто обмежити ключ своїм доменом `*.github.io`.
- **alerts.in.ua** (необов'язково): токен за запитом на alerts.in.ua/api-request. Дає банер «тривога» і статус у верхній смузі.

## Як читати екран
- Верхні «чіпи» — стан кожного джерела: зелений означає свіжі дані, жовтий — показано останній знімок або частина даних ненадійна, червоний — немає зв'язку.
- **Ділянки**: швидкість зараз / звичайна і «довіра» TomTom. Довіра < 50% → сіра «ненадійно». Саме тут видно, як тривога впливає на дані.
  Додати ділянку: утримати палець на карті.
- **Маршрути**: час зараз, без заторів, «зазвичай» (історичний для цього часу) і ремонти КМДА в межах ~40 м від маршруту.
- **Ремонти**: пошук за вулицею або виконавцем; червоне — повне перекриття, помаранчеве пунктиром — часткове.

## Якщо ремонти не вантажаться
Імовірно, браузер блокує прямий запит до геосервера міста (CORS). Розгорніть `cloudflare-worker.js` (інструкція в самому файлі)
і впишіть його адресу з `?url=` у «Налаштування → Посередник».

## Обмеження
- Покриття Києва живими даними TomTom і їхню якість під час тривог треба перевірити на практиці: перші дні дивіться на «довіру» в ділянках.
- Сповіщень без відкритого застосунку немає. Для «виїжджай раніше» знадобиться бот (наступний етап).
- Плитки OpenStreetMap кешуються лише ті, що ви переглядали; масове завантаження карти правила OSM забороняють.
- Не робіть посилання публічно відомим: Google з міркувань безпеки прибрав в Україні загальний шар заторів, тож відкриту для всіх живу карту краще не поширювати.
